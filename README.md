# Trabalho Final - Front-End I

Projeto acadêmico desenvolvido com HTML5 e CSS3.

## Estrutura

- `index.html` — estrutura da página
- `style.css` — estilos CSS
- `imagens/` — imagens utilizadas no site

## Como abrir

Basta abrir o arquivo `index.html` no Google Chrome, Microsoft Edge ou outro navegador.

## Tema

Cafeteria fictícia: Café Aurora.

## Conceitos utilizados

HTML5, CSS3, tags semânticas, imagens, links internos e externos, listas,
tabela, seletores CSS, espaçamento, cores e media queries para responsividade.
